Digital Accessibility
Auditing & Compliance Suite

AMASAMYA is a blind-first, offline-first digital accessibility suite designed to evaluate mobile apps, web portals, and software against WCAG 2.2, GIGW 3.0, IS 17802, and international VPAT 2.5 standards.

📱 Get it on Google Play 💻 GitHub Repository

Why AMASAMYA?

👁️‍🗨️

Blind-First Design

Engineered from the ground up for screen-reader users (TalkBack, NVDA, JAWS). Merged semantics, non-blocking overlay flags, and spoken utterance timelines.

🔒

100% Offline & Private

All screen inspection, color contrast analysis, and TalkBack focus path tracing execute entirely on-device. Zero telemetry, zero external servers.

📜

VPAT 2.5 INT Exporter

Export self-contained VPAT 2.5 ACR compliance reports in Executive PDF, Excel CSV, HTML, and Markdown format for enterprise procurement.

Core Audit Capabilities

🎯

Touch Target Inspector

Validates interactive button dimensions against 48dp (Android/IS 17802) and 44dp (WCAG 2.2 AA) minimum target requirements.

🔄

TalkBack Focus Trail Visualizer

Dynamically maps sequential screen-reader swipe paths to detect focus traps, out-of-order nodes, and unlabelled interactive controls.

🎨

Color Blindness Simulator

Simulates Protanopia, Deuteranopia, Tritanopia, and Monochromacy vision filters to verify non-color-dependent UI design.

Compliance Standards Coverage

AMASAMYA evaluates digital applications across national and international accessibility frameworks:

Framework / Standard Jurisdiction Scope Covered Compliance Status
WCAG 2.2 (Level A, AA, AAA) Global / W3C Perceivable, Operable, Understandable, Robust Supported
GIGW 3.0 India (Government Websites & Apps) Mandatory Rules 4.1, 5.2, 6.3, 7.1 Supported
IS 17802 (Part 1 & 2) India (Bureau of Indian Standards) ICT Accessibility for PwD (48dp target, contrast) Supported
VPAT 2.5 INT (ACR) Global / Enterprise WCAG 2.2, Section 508, EN 301 549 Edition Supported
US Section 508 United States (Federal Procurement) Chapter 5 Software & Chapter 7 508 E205.4 Supported
EU EN 301 549 European Union (EAA 2025 Mandate) Chapter 9 Web & Chapter 11 Software Supported

Developer Integration Guide

Integrate AMASAMYA accessibility assertions directly into your Jetpack Compose tests or CLI pipelines:

1. Jetpack Compose Automated Test Assertion

@Test fun verifyAccessibilityCompliance() { composeTestRule.onNodeWithContentDescription("Submit Audit") .assertExists() .assertHasClickAction() }

2. Web Linter CLI Execution (`amasamya-linter.js`)

node amasamya-linter.js index.html --standard=WCAG22_AAA --gigw=3.0
